# Affective Intermediation in Twin Cities Nonprofit Communication — Data Guide

## Primary analytical universe

114 independent eligible/probably eligible organizational, program, and network units serving or representing immigrant/refugee communities in the Twin Cities.

Study period: **November 1, 2025–March 31, 2026**.

## Data locations

### Sampling frame
`research_workspace/01_sampling_frame/`

Key file:
`eligibility_screening_summary_v1.md`

### Platform registry
`research_workspace/03_platform_registry/`

Contains official website/social account verification, archive retrievability, and analysis-scope status.

### Raw communication data
`research_workspace/05_data/raw/`

One organization-owned communication item per row. Website and social-platform versions remain separate observations.

### Interim data
`research_workspace/05_data/interim/`

Contains matched-message candidates, engagement schemas, and other linked intermediate products.

### Processed data
`research_workspace/05_data/processed/`

Reserved for analysis-ready merged corpora, reliability samples, manual-coding sheets, and final coded datasets.

## Public engagement data

Post-level engagement fields include, where publicly observable:

- reactions/likes
- comments
- shares/reposts
- views
- organization replies
- public replies
- capture date
- visibility/retrieval status

Interaction-level records preserve visible comment/reply meaning while anonymizing ordinary public users.

## Circulation data

When official repost/share totals are unavailable, the project may store a **minimum observed recirculation count** based on defensible public traces. This must never be treated as equivalent to a platform's total share/repost count.

## Data-quality rules

- Search miss ≠ absence.
- Verified account ≠ complete archive.
- Hidden engagement ≠ zero.
- Event date ≠ publication date.
- Same date ≠ matched message.
- Repost trace ≠ canonical organization post.
- Month-only records remain outside weekly analyses.
- Unresolved candidates remain separate from the strict primary corpus.

## Observability

Website communication is comparatively well observed. Historical social-media archives are uneven and platform-dependent. Social-media analyses therefore use a bounded public-web recovery design and report observability limitations explicitly.
