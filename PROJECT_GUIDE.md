## Conceptual model

`crisis → organizational appraisal → affective production → public uptake → affective circulation → possible conversion/action`

Four empirical layers:

1. Affective production
2. Affective uptake
3. Affective circulation
4. Affective conversion

## Study period

November 1, 2025–March 31, 2026.

## Important methodological guardrails

- Communication availability is not an organizational eligibility criterion.
- Missing social posts are not organizational silence.
- Hidden engagement is NA, not zero.
- Engagement volume is not emotion intensity.
- Cross-platform versions remain separate observations even when linked as matched messages.
- Candidate/unresolved items remain outside strict primary counts until verified.
- Visible comments are public traces, not representative public opinion.

## Project history

The repository began with a smaller AEJMC 2026 nonprofit communication/media-audit project. That earlier design is preserved as project history and methodological precursor, but the current flagship project is the 114-unit Affective Intermediation study.
